# Анкета и панель креаторов

Прототип: страницы публикуются на GitHub Pages, а анкеты, оценки, комментарии и загруженные файлы хранятся на отдельном сервере в SQLite и файловом каталоге. На текущем этапе панель и её данные доступны без входа всем посетителям; участникам анкеты показано соответствующее уведомление.

`index.html` и `assets/` — интерфейс, `backend/` — приложение и конфигурация сервиса. Сервер привязывается к localhost и работает за HTTPS через nginx. База данных и файлы хранятся вне репозитория, не помещайте их или ключи в Git.
